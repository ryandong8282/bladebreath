# 产品愿景与范围

## 一句话定位

《无铭：漳城夜》是一款 **iOS 优先的固定斜俯视 3D 硬核动作游戏**。它以北齐末年为历史母体，但使用完全架空的王朝、人物与事件：玩家操纵一具没有姓名的武俑，以武器为动作骨架、以军系流派为战斗哲学，在漳京亡国前夜的小规模高压战斗中读招、拼刀、破势并追索自己被删除的军籍。

内部开发代号仍为 `BladeBreath / 刃息`。

## 核心承诺

### 给动作玩家

- 输赢首先取决于是否看懂敌人的刀，而不是攻击力是否足够；
- 防守不是单一弹反按钮，而是守、弹、闪、迎刀、抢断与拉开距离的选择；
- 同一把武器换流派，应形成完全不同的攻防循环；
- Boss 的强度来自招式关系和判断压力，不来自满屏地板火。

### 给历史氛围玩家

- 不在界面上标注“北齐改编”，而让地理、军制、石窟、墓葬壁画、铸币、服饰与政治结构共同构成可推断线索；
- 超自然现象从“造像、墓室、军籍、誓文、功德与失名”中生长；
- 任何器物和制度设计都要能说明历史来源、架空变化与游戏功能；
- 不使用泛武侠模板填空，不把唐宋元明清元素随手混入六世纪北方。

## 不是什么

- 不是怪海割草；
- 不是满屏投射物的动作肉鸽；
- 不是开放世界；
- 不是装备词条无限叠加的刷宝游戏；
- 不是把某一款商业动作游戏缩小到手机；
- 不是“把历史人物全改一个字”的影射同人；
- 不是猎奇展示北齐皇室轶闻的变态博物馆。

借鉴只停留在可公开讨论的抽象设计：武器动作组、流派技能、战斗资源、架势与短局构筑。角色、技能、动画、UI、关卡、模型、剧情与数值必须原创。

## 三层产品结构

### 1. 一刀一回合

最底层体验是单次交锋：敌人蓄势、玩家判断、兵器接触、结果反馈。即使没有掉落和成长，这一刀也必须有趣。

### 2. 武器 × 军系流派

- 武器决定攻击距离、节奏、重量、动作、固定武技；
- 流派决定如何获得锋意、怎样处理敌招、技能如何衔接；
- 同一把长刀配“听刃”与“流影”，应像两个角色，而不是两套颜色。

### 3. 亡国夜远征

每次进入漳京，造像署都依据互相矛盾的军报、碑记与口供重建当夜。空间和敌人有受控变化，玩家本局获得“悟招”，死亡后留下被恢复的姓名、军籍、证词和永久知识。

## 核心玩家体验

一场漂亮战斗后，玩家应该有三种感觉：

1. **我看懂了。** 敌人的危险动作可以观察和解释；
2. **我做到了。** 胜利来自判断和执行，而不是单纯等级压制；
3. **我还能更漂亮。** 同一战斗存在更快、更险、更符合流派的解法。

剧情推进后还应多一层感觉：

4. **我好像知道这是哪个时代，但这里的历史不完全可信。**

## 六根设计支柱

### 1. 小规模高密度战斗

普通战斗以 1–3 个敌人为主。每个敌人拥有有限、清晰、能组合的招式，不用数量掩盖动作和 AI 问题。

### 2. 武器决定身体，流派决定脑子

第一把武器为镇军长刀；第一批流派为听刃和流影。未来的双刃、步槊、重兵只在长刀验证成功后进入开发。

### 3. 架势管理“能否站住”，势权表现“谁在掌控”

生命决定能否继续战斗，架势决定是否露出破绽；势权线表现当前交锋的主动权。三者职责必须分开，不能堆成三个换皮血条。

### 4. 技能由操作供能

锋意通过弹反、主动拼刀、精准闪身和持续压迫获得。技能用来扩大玩家已经争取到的优势，不鼓励绕圈等待冷却。

### 5. 历史线索必须服务游戏

历史研究不是装饰性百科。每条线索至少服务一种功能：视觉识别、敌人动作、关卡结构、剧情冲突或道具叙事。

### 6. 为手机设计

- 横屏；
- 主操作不超过移动、攻击、格挡、闪身、两个技能；
- 自动朝向当前主要威胁，但限制吸附角度；
- 轮廓、动作前摇和音效先于华丽特效；
- 默认目标 60 FPS，兼容档允许 30 FPS。

## 当前第一份交付

M0.3 包含：

- Unity 6.3 LTS 主工程骨架；
- 一把长刀的首轮 C# 战斗移植；
- 一个造像署执刃者；
- 校刀院灰窑外院程序化灰盒；
- 生命、架势、攻击、格挡、起手弹反、闪身、崩势和处决；
- 桌面与手柄基础输入；
- 可直接运行的浏览器历史参考版；
- 北齐历史母体、美术与剧情圣经；
- Godot M0.2 保留在 Git 历史中。

听刃、流影、锋意、主动拼刀、触屏与完整肉鸽房间层仍待在 Unity 中恢复和验证。

## 当前成功判断

- Unity 项目能否在固定版本中无错误编译并稳定重置；
- 测试者能否在三次失败内说出敌人为什么打中自己；
- 弹反、格挡、普通命中和不可格挡攻击是否有不同反馈；
- 同一敌人是否值得重复打十次；
- 恢复两种流派后，玩家是否自然改变打法；
- 触屏误触是否成为主要失败原因；
- 截图是否呈现“六世纪北方末世”而不是泛古风；
- 玩家能否从只言片语推断王朝将亡，而不需要先读历史论文。
