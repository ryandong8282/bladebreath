# 北齐末年历史母体圣经 v0.1

本文件不是历史论文，也不是剧情梗概。它是所有设计、文案、美术和关卡的共同约束：哪些东西来自真实历史，怎样被架空转换，哪些时代错位不可接受。

## 1. 时间与空间锚点

### 历史母体

- 朝代：北齐，550–577；
- 取材重心：570 年代、灭亡前夕；
- 核心地理：邺城所在的漳水平原、晋阳军事中心、向西连接关中的战争方向；
- 政治气质：强盛资源与迅速崩溃并存，军事集团、宫廷、宗教工程和地方秩序互相拉扯。

### 架空转换

| 历史锚点 | 游戏名称 | 转换原则 |
|---|---|---|
| 北齐 | 大衡 | 不使用真实皇帝、年号和政权名称 |
| 邺城 | 漳京 | 保留漳水平原都城关系，不复刻真实城市地图 |
| 晋阳 | 晋垒 | 保留北方军事中心功能，城市结构原创 |
| 北周 / 关中敌国 | 西军 / 西国 | 不直接套真实君臣，保留地缘压力 |
| 南陈 | 江朝 | 仅作为南方政治存在，不在首章展开 |
| 突厥诸部 | 北庭诸部 | 保留外交与军事牵制，不做单一蛮族模板 |
| 北齐造像工程与石窟 | 万像工程 / 造像署 | 将视觉和政治功能转化为核心科幻式奇诡机制 |

任何新增地点必须先回答：它在漳京、晋垒、关中、北庭和江南关系中处于哪里。

## 2. 玩家能够推断时代的线索梯度

### 明线：普通玩家能读懂

- 北方王朝；
- 都城奢华、边关告急；
- 大规模凿佛与功德工程；
- 军人政权内部清洗；
- 胡汉姓名、语言和服饰并存；
- 骑兵、军镇、石窟和墓葬仪仗构成主要视觉。

### 中线：对南北朝有印象的玩家会怀疑

- 首都靠近漳水；
- 北方另有一个比首都更像军事根基的晋地中心；
- 西方关中政权在短期内迅速推进；
- 王朝看似富庶强大，却因政治和指挥崩溃迅速瓦解；
- 石窟工程位于都城与北方军事中心之间的交通线上。

### 暗线：历史爱好者可以拼出

- 架空钱币“常衡五铢”对应常平五铢；
- 铭文纪年、军镇称谓、造像题记和墓葬图像存在精确的六世纪北方影子；
- 某些战报的日期、行军方向和君臣清洗顺序形成对真实史事的远距离呼应；
- 但每条线索都至少改动一个关键关系，避免变成猜真实人物姓名的谜语游戏。

## 3. 国家与组织

### 大衡朝廷

不是纯粹疯人院。它必须同时具备：

- 高效的一面：税粮、军队、都城工程和交通网络确实运行过；
- 脆弱的一面：政治恐惧让命令和人事不断被改写；
- 诱人的一面：很多角色真心相信统一武艺和记录能结束乱世；
- 残酷的一面：国家把人的姓名和身体当作可替换资源。

### 造像署

架空机构，吸收但不等同于真实佛教造像作坊。

职能：

1. 管理皇室造像工程；
2. 征调石匠、陶工、画工和运输役；
3. 保管军籍、誓文和处刑记录；
4. 将武者动作制成可重铸武俑；
5. 通过“校刀院”验证动作是否符合档案。

造像署内部应存在技术官僚、宗教解释者、军官、工匠和被迫劳动者，不是一群统一念邪咒的反派。

### 军系，而非武侠门派

| 军系 | 社会来源 | 战斗倾向 |
|---|---|---|
| 镇军 | 北方边镇旧军 | 正面对刀、稳守、压势 |
| 羽林 | 宫廷近卫与处刑机构 | 贴身、短招、换位、追击 |
| 并州军 | 晋地军镇、下马重骑与步槊兵 | 距离、截击、站位控制 |
| 西军 | 关中敌国 | 队列、重甲、纪律、组合攻击 |
| 役军 | 工匠、河工、运输役临时武装 | 工具武器、陷阱、环境利用 |

“流派”是玩家界面用语，世界内更常叫“某军式”“某家手”“某营谱”。

## 4. 宗教与超自然边界

游戏可以表现佛教功德、造像、轮回想象、墓葬守护、天界图景、誓言和姓名禁忌，但不直接判定某一真实宗教教义为邪恶。

超自然机制的解释保持多义：

- 官员称之为刻录和重铸技术；
- 僧人认为这是执著造成的假生；
- 军人认为只是训练被保存；
- 工匠认为材料会记住受力；
- 玩家永远无法获得完全客观的说明书。

禁止无来源加入：

- 西式地狱恶魔体系；
- 后世成熟道教符箓战斗模板；
- 修仙境界、灵根、御剑宗门；
- 唐以后禅宗公案式语言直接套用；
- “佛像必然邪恶”的单调表达。

## 5. 物质文化基准

### 可用视觉材料

- 石灰岩造像，局部残彩和鎏金；
- 石窟、佛龛、莲座、背光、题记；
- 墓道壁画中的骑兵、侍从、宴饮、乐舞、旗帜与骆驼；
- 陶俑、陶器、灰窑和运输架；
- 橄榄绿色釉陶与西来器形；
- 铸造铜钱、方孔钱、简短铭文；
- 木构、夯土、砖石混合建筑；
- 北方军用长刀、槊、弓、盾、重兵的原创化设计。

### 谨慎使用

- 甲胄细节：考据不足时优先做大轮廓，不编造密集纹样；
- 发式与冠帽：不同身份需单独查证，不用影视剧“古装头套”；
- 胡汉身份：不依靠鼻子、胡子或肤色刻板区分；
- 佛教手印与造像组合：作为正式叙事元素前需二次核对；
- 文字字体：避免使用明显晚出的碑帖风格冒充六世纪原样。

### 明确禁用的时代错位

- 日本打刀、武士甲、鸟居；
- 宋代官帽、明代飞鱼服、清代辫发；
- 辽金覆面作为大衡标准装备；
- 元末以后成熟火器体系；
- 明清家具、牌楼、园林和客栈模板；
- 现代“江湖门派大会”组织结构；
- 西欧板甲和哥特建筑无解释混入。

## 6. 语言风格

### 原则

- 现代玩家能看懂；
- 避免整段伪古文；
- 官文、军令、工匠口语和民间传闻有明显区别；
- 术语少而稳定；
- 不使用网络玄幻常见词堆砌“古味”。

### 示例

军令：

> 西门闭。诸营不得换籍。无铭者，就地拆毁。

工匠：

> 他胸口那块不是没刻，是刻了又磨，磨了又刻。

碑记：

> 靖平七年冬，奉为国主凿像。未竟，西尘入城。

不推荐：

> 天命轮回，万古诸天，神魔血脉于此觉醒。

## 7. 剧情考据流程

新增重要内容时，提交以下五项：

```text
1. 历史锚点是什么？
2. 架空后改了什么？
3. 为什么有利于玩法或主题？
4. 玩家通过什么线索看见它？
5. 是否引入时代错位或现实群体刻板印象？
```

没有答案的“古风酷点子”先放入许愿池，不进入生产。
