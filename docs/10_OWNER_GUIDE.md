# 老板试玩指南

你不需要先学 Godot、状态机、动画树、北齐史或数值设计。当前最重要的工作是亲手打一小会儿，然后说真实感觉。

## 最快打开方式

下载或克隆仓库，然后双击：

```text
prototype-web/index.html
```

点击“开始试刃”即可。浏览器版不是假视频，玩家、敌人、攻击、弹反、闪身、拼刀、架势与两套流派都在实时运行。

## 你只需要回答四句话

```text
1. 我在哪一刻觉得爽？
2. 我在哪一刻不知道自己为什么挨打？
3. 哪个按钮最难按或最容易按错？
4. 我死后还想不想马上再来一次？
```

“太慢”“太飘”“刀像纸片”“敌人那一下看不懂”“按钮挡住人”“我弹到一次很爽”，这些都是有效反馈。

## 再补一个世界观问题

试玩一会儿后，随口说一句：

> 你觉得这像哪个历史时期，依据是什么？

不要求猜对。这个问题用来检验环境线索是否有效，而不是考试。

## 暂时不要评价

M0.2 阶段不用纠结：

- 人物是否帅；
- 场景是否像商业 3A；
- 剧情是否够长；
- 武器是否够多；
- 特效是否华丽；
- 能不能卖钱；
- 真实北齐细节是否已经全部做出来。

当前只判断战斗闭环值不值得继续，以及历史方向有没有跑成泛古风。

## 新愿望怎么说

直接自然语言许愿，例如：

> 我希望步槊不是长刀换皮，而是在敌人靠近之前就能架开他。

> 我希望宫城那帮人打起来很讲礼仪，但下手比边军更阴。

愿望会先进入 `docs/WISH_POOL.md`。只有能解决当前试玩问题，且不让范围爆炸，才进入本轮。

## Godot 版本

浏览器打完后，再在 Godot 4.7.2 Standard 中导入 `project.godot`，检查真正 3D 版本。当前交付环境没有 Godot 可执行文件，所以这一步交给 GitHub Actions 和装有 Godot 的电脑继续验证。

你负责许愿和说感受；项目负责把愿望压缩成可以验证、可以完成、不会失控的下一步。
