# 老板试玩指南

你不需要先学 Unity、状态机、Animator、Shader、北齐史或数值设计。当前最重要的工作仍然是亲手打一小会儿，然后说真实感觉。

## 两种试玩方式

### 1. 最快看旧设计

下载或克隆仓库，双击：

```text
prototype-web/index.html
```

它保留旧样机更完整的两套流派和技能，适合快速理解原来的战斗想法。

### 2. 玩正式主工程

1. Unity Hub 安装 `6000.3.23f1` 和 iOS Build Support；
2. 打开仓库根目录；
3. 等待脚本编译；
4. 执行 `BladeBreath > Prototype > Create Combat Sandbox`；
5. 点击 Play。

Unity 版当前只恢复了核心交锋子集。看到灰胶囊、方块刀和简陋 HUD 是正常的，这不是最终美术。

## 你只需要回答四句话

```text
1. 我在哪一刻觉得爽？
2. 我在哪一刻不知道自己为什么挨打？
3. 哪个按钮最难按或最容易按错？
4. 我死后还想不想马上再来一次？
```

“太慢”“太飘”“刀像纸片”“敌人那一下看不懂”“我弹到一次很爽”，都是有效反馈。不要替程序员猜解决方案，先说发生了什么和你感到什么。

## 再补一个世界观问题

试玩后随口回答：

> 你觉得这像哪个历史时期，依据是什么？

不要求猜对。它检验环境线索，而不是考试。

## 当前暂时不要评价

- 人物够不够帅；
- 场景像不像商业 3A；
- 剧情够不够长；
- 武器够不够多；
- 特效够不够华丽；
- 能不能马上卖钱；
- 是否已经做成完整《暖雪》。

当前只判断：Unity 迁移后的一刀值不值得继续，失败是否讲得清楚。

## 新愿望怎么处理

自然语言许愿即可，例如：

> 我希望步槊不是长刀换皮，而是在敌人靠近前把他架开。

愿望先进入 `docs/WISH_POOL.md`。只有能解决当前试玩问题、符合里程碑且不让范围爆炸，才进入本轮。

你负责许愿和说感受；项目负责把愿望压缩成可验证、可完成、不会失控的下一步。
