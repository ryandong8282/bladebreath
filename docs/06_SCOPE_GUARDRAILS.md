# 绝不现在做的东西

这份文件专门拦截“老板突然又想到了一个牛逼功能”。任何人，包括老板本人和 AI，在当前里程碑未通过前都不得把以下内容塞进主线。

## M0 前禁止

- 第二把武器；
- 正式角色模型；
- Boss；
- 剧情过场；
- 装备掉落；
- 存档；
- 商店；
- 地图生成；
- 属性加点；
- 联机；
- 排行榜；
- 成就；
- 内购。

## M2 前禁止

- 开放世界；
- 无缝大地图；
- 五种以上武器；
- 多角色切换；
- 复杂元素反应；
- 装备稀有度与随机词条；
- 锻造、炼药、采集；
- 全程配音；
- 分支对话树；
- 程序生成 3D 关卡；
- 赛季、通行证、抽卡。

## 新愿望处理流程

任何新想法先写成一句话，放进 Backlog，并回答：

1. 它解决当前哪个已观察到的玩家问题？
2. 不做它，当前里程碑是否无法验收？
3. 它会引入哪些新的资源类型、UI、存档字段和测试组合？
4. 有没有只用现有系统达到 60% 效果的更小方案？

如果第 2 题答案为“否”，默认不进入当前里程碑。

## 第一原则

> 不是把愿望都做出来，而是找到最小的一组系统，让玩家真正感到“我在和敌人交锋”。
