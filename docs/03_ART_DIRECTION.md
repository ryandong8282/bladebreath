# 美术方向：石窟残彩与灰窑铜火

## 总体命题

《无铭：漳城夜》不做泛化的“水墨武侠”，也不靠黑红两色假装暗黑。视觉母体来自六世纪北方的石灰岩造像、残留矿物颜料与鎏金、墓道仪仗壁画、陶俑、灰窑、旧木、铜铁兵器和跨地域器物。

目标是：

> **玩家第一眼觉得陌生、肃穆、危险；多看几眼能猜出是南北朝北方，而不是唐宋明清拼盘。**

## 关键词

```text
北方末世 / 石窟残彩 / 灰窑 / 墓道仪仗 / 军镇旧铁
灰白石灰岩 / 褪色朱砂 / 铜金残片 / 橄榄青釉 / 烟黑木构
低多边形 / 大轮廓 / 少材质槽 / 手机可读性
```

## 历史视觉锚点

### 石窟与造像

北齐造像常见石灰岩本体，并保留颜料或鎏金痕迹。游戏不把佛像做成纯白现代雕塑，而应出现：

- 灰白、微黄、带凿痕的石材；
- 局部残留朱、赭、青绿和暗金；
- 被烟熏、雨蚀、重修和人为刮除的表面；
- 体量巨大的局部肢体、背光、莲座或残面，作为关卡尺度参照。

### 墓道壁画与仪仗

骑兵、侍从、旗帜、宴饮、乐舞、骆驼与行列不是背景花纹，而是构图语言：

- 关卡墙面采用横向行列和重复人物节奏；
- 敌人编队先像“仪仗”，进入战斗后才拆成攻防关系；
- UI 章节图使用墓道长卷式构图，不使用日式浮世绘框架；
- 角色的身份优先通过队列位置、武器、旗号和护具层级表达。

### 陶器、青釉与跨地域纹样

北方城市并非封闭的汉地古镇。器物可以出现西来形制、胡旋舞、乐工、商旅与绿釉陶，但必须通过本世界的工艺重画，不能直接使用后世“异域集市”模板。

## 核心色盘

建议以材质比例而非技能属性配色：

| 用途 | 颜色倾向 | 画面职责 |
|---|---|---|
| 烟黑 / 墨褐 | `#090A08`–`#24231F` | 背景、木构、未照亮空间 |
| 石灰灰 / 骨白 | `#BDB6A6`–`#E7DFCF` | 玩家、造像、可读轮廓 |
| 旧铜 / 暗金 | `#74572F`–`#B58A4D` | 身份、势权、重要结构 |
| 褪朱 / 血赭 | `#6D2118`–`#AD3826` | 危险、处决、军令印记 |
| 橄榄青釉 | `#526B55`–`#718876` | 少量器物、流影提示 |
| 灰青铜锈 | `#5D8A80`–`#91BFB3` | 防御、弹反、听刃反馈 |

基础画面控制在：

- 65% 烟黑、灰褐、旧木；
- 25% 石灰灰、土色；
- 10% 朱、铜、青绿高亮。

高饱和色只用于需要在 0.2 秒内识别的危险和成功反馈。

## 镜头与空间

- 固定或缓慢变化的斜俯视镜头；
- 正交或极弱透视；
- 俯角约 40–50°；
- 地面必须提供距离标尺：铺砖缝、车辙、仪式圆线、窑场刮痕；
- 高墙、佛像和柱体遮挡角色时必须裁切、淡出或采用缺口；
- 竞技场边界首先由建筑和人群逻辑形成，其次才是空气墙。

## 第一场：校刀院灰窑外院

M0 浏览器版提供了信息层级；Unity 试玩后将空间构图修正为：

- 横向长方形旧石校院占据整个屏幕，镜头正对建筑轴线，不把房间投影成菱形；
- 中央保留椭圆形旧石战圈作为距离标尺，战圈不是房间外轮廓；
- 院墙外继续绘制灰土地、道路、断墙、碎石和远窑，不允许直接落入黑色虚空；
- 后方一尊未完成、被裁切在镜头外的巨大造像；
- 两座灰窑铜火提供暖色定位；
- 四周木架、碑牌与封门军令形成边界；
- 无铭者使用石灰白轮廓，执刃者使用烟黑和旧铜；
- 拼刀使用灰白火花，弹反使用灰青弧光，不使用彩虹技能。

这一版仍是灰盒，但以后所有正式资产替换都必须保留它的信息层级。

## 角色原则

### 无铭者

- 中等体型，肩、胯、刀长一眼可读；
- 身体像被灰窑重新拼接的武俑，但不能变成机械人；
- 胸前保留一块本应刻军籍却被磨平的铭板；
- 材质以灰白陶、旧布、局部金属为主；
- 流派差异通过站姿、脚步残影、刀光和少量挂件表达，不每次重做全身皮肤。

### 造像署执刃者

- 与无铭者共享“武俑”血缘，但轮廓更完整、铭牌更清楚；
- 面部可以是窄缝面具或未开眼的陶面；
- 受伤时先出现釉裂和内部铜红，不做湿亮血浆喷泉；
- 重招前摇由全身重心和刀路表达，红色提示只做二次确认。

### 后续敌人

- 羽林近卫：上窄下稳、动作短、贴身取消多；
- 并州步槊：长纵向轮廓，站位就是威胁；
- 西军重兵：宽肩、低重心、甲片成大块面；
- 造像役：背负绳具、木架、泥坯或刻刀，战斗方式来自工作工具。

## VFX 语法

| 结果 | 形状 | 颜色 | 持续 |
|---|---|---|---|
| 普通命中 | 短扇形刀痕 + 少量碎屑 | 灰白 / 土红 | 极短 |
| 格挡 | 向防守方塌缩的火花 | 暗铜 | 短 |
| 弹反 | 清晰外扩圆弧 | 灰青 + 白心 | 短且亮 |
| 压刀胜利 | 沿刀路向敌人推进 | 旧铜 | 中短 |
| 架势崩溃 | 陶釉裂纹沿身体扩散 | 铜红 | 中等 |
| 处决 | 画面减色、单次朱红 | 朱砂 | 不拖尾 |
| 不可格挡 | 敌人武器或身体上的实心红边 | 褪朱 | 只在必要窗口出现 |

## UI 语言

- 版式参考碑额、题记、军籍木牍和印章，不直接仿古卷轴；
- 中文标题可用系统宋体兜底，仓库不分发字体文件；
- 面板以细铜线、暗底、留白构成，不使用雕花大边框；
- 图标先做单色形状，再考虑残彩；
- 生命、架势、锋意和势权必须形态不同，不能全是横条换颜色。

## 时代红线

禁止直接出现：

- 明清官帽、飞鱼服、锦衣卫式样；
- 清代辫发；
- 日本武士刀、鸟居、和风家纹；
- 宋以后成熟样式的盔甲、家具和城市街景；
- 辽金金属覆面、元明火器作为常规六世纪装备；
- 西式哥特教堂、恶魔角、维京符文等无世界内来源元素；
- “青龙白虎朱雀玄武 + 水墨 + 红伞”式泛国风拼贴。

架空允许改变比例、组合与功能，但每次越界必须在历史圣经中登记理由。

## 生产策略

第一章场景优先建立小型模块库：

- 石灰岩墙、佛龛、莲座、残肢；
- 灰窑、木架、石料、泥坯；
- 墓道式壁画墙片；
- 柱础、门、阶、军令碑、铜火盆；
- 旧布旗、绳具、运输架；
- 石、陶、木、铁、铜、残彩六套基础材质。

不要为每个房间制作独立资产。通过尺度、残彩、灯火、雾尘和摆放关系形成差异。
