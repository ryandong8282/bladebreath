# 老板许愿池

这里接住“突然想到一个牛逼东西”。写下来不等于立刻做；我会把愿望压缩成能验证的版本。

## 五问

1. 是否强化“读招 → 锋意 → 流派技能 → 破势处决”？
2. 能否在现有按钮数内成立？
3. 能否在校刀院小场景验证？
4. 会不会让单人项目内容量翻倍？
5. 能否在北齐末年母体中找到可信来源，而不是一句“架空就行”？

回答后进入 `本轮`、`以后` 或 `坟场`。

## 本轮

- 长刀的听刃和流影必须形成两种明显打法；
- 造像署执刃者稳定教会普通斩、延迟斩和不可格挡横扫；
- 完成浏览器首轮试玩；
- 把“势权”验证为有用信息，而不是第三根多余血条；
- 校刀院灰窑外院保持北齐石窟、陶窑、军令和墓道构图线索；
- 第一名小头目“校刀令·迟盖”只做招式纸面规格，不进代码堆内容。

## 以后

- 双刃：羽林近卫体系，高频贴身、取消和追身；
- 步槊：并州军系，距离控制、截击和架开；
- 斩马重兵：守城军系，重压、霸体和架势粉碎；
- 拼刀火花沿真实碰撞点飞散；
- Boss 识别玩家重复防守习惯；
- 错籍改变小头目第二阶段；
- 万佛坑的巨像断肢形成战斗空间；
- 墓道仪仗壁画随记录变化而改写人物位置；
- 常衡五铢成为可推断时代的细节道具。

## 坟场（现在不做）

开放世界、八人联机、一百把随机词条武器、建房种菜结婚、首发三十个 Boss、真实北齐皇帝大乱斗、把所有变态轶闻做成猎奇关卡、骑马弓战大地图、抽卡和全程电影化配音。
