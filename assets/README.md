# Asset workspace

M0.2 deliberately ships without downloaded art packs. The arena, weapon, combatants, telegraphs, HUD and browser presentation are generated from primitives and code so combat and the Zhangcheng visual hierarchy can be tested before formal art production.

Planned folders:

- `art/` — concept sheets, UI source and textures;
- `models/` — authored or generated `.glb` models;
- `vfx/` — VFX textures and shader resources;
- `audio/` — impacts, clashes, ambience and music stems.

Every non-code asset added later must be recorded in `ASSET_LICENSE.md` with its author, generation method or source license. Do not commit unverified marketplace downloads.
