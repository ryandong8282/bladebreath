# 无铭：漳城夜 — 浏览器战斗验证版

这是一个零依赖 HTML Canvas 灰盒。它不是宣传视频，而是一套实时战斗实现，用于在安装 Godot 和制作正式 3D 资产前验证核心手感。

## 运行

直接双击 `index.html`，无需联网、npm 或本地服务器。

## 当前战斗

- 长刀三段攻击；
- 按住格挡与起手弹反；
- 闪身与完美闪避；
- 主动拼刀；
- 生命、架势、锋意和实验性的势权线；
- 架势崩溃后的近身处决；
- 听刃式：震刃、回锋；
- 流影式：掠影、追风斩；
- 普通斩、延迟重斩、快速回身斩和不可格挡横扫；
- 键盘、鼠标和触屏按钮；
- 命中停顿、镜头震动和粒子反馈。

## 控制

```text
WASD / 方向键     移动
J / 鼠标左键      攻击、连段、处决
按住 K / 右键     格挡；起手短窗口为弹反
Space / Shift     闪身
Q / U             武技一
E / I             武技二
Tab               切换听刃 / 流影
R                 重置
```

## 场景

时间为靖平七年冬，地点是漳京造像署的校刀院灰窑外院。无铭者必须击败仍在执行封门军令的“造像署执刃者”。

## 自动验证

用于自动测试：

```text
?autostart=1
```

页面会暴露只用于测试的 `window.__bladeBreath` 对象。

## 代码地位

浏览器版是快速手感实验，不是未来正式架构。经过试玩确认的时间窗、距离和反馈会回填 Godot 主工程；不会长期把两套产品逻辑各自扩张。
