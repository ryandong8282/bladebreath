# Asset licensing

The current prototype uses procedural primitive meshes, Canvas drawing, colors,
text, code-generated UI, and synthesized presentation. No third-party art,
audio, animation, font, texture, or model asset is included.

## Current generated artifacts

| Asset | Method | License / status |
|---|---|---|
| `assets/icon.svg` | Original vector created for the project | Project-owned placeholder |
| `prototype-web/*` presentation | Original code-generated shapes, particles and UI | Covered by repository code license |

Museum and historical links in the design documents are research references,
not bundled production assets. Even when a source marks an image Public Domain,
using it in the game requires a new entry recording the exact source, object ID,
license, modifications, and production purpose.

Generated concept art remains reference material unless a later entry explicitly
marks it production-ready and records the model/tool, date, prompt lineage, human
changes, and intended distribution rights.
